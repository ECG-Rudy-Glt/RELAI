## Reading

- **One repository: no difference.** The agents found the decisive note or commit by themselves in every run. The
  handoff did not save tokens there either.
- **Linked repositories: the whole difference.** Without the handoff, 0 of 30 runs noticed that a repository the app
  depends on had changed; with it, 28 of 30 did (Haiku 12/15, Sonnet 15/15). Token use was about the same.

## Limits

- In the `repo` condition nothing tells the agent that linked repositories exist except the `links:` line of
  `relai.yaml`, and the prompt does not mention them. An `AGENTS.md` that names the dependencies, or a person telling the
  agent, could close part of the gap: not tested. The comparison is "an agent alone in its repository" against "the same
  agent with the handoff".
- In the m tasks the decisive fact is in the linked repository's commit message and dated notes, which is what handoff
  v0.10 shows. The task author did not know Relai, but the protocol (a fact written in the repository state) fits it.
  A change recorded only in code, without a commit message or note, would not be shown.
- One vendor (Claude), 5 runs per cell, 6 tasks. Codex: instructions in `eval/resume/CODEX.md`.
