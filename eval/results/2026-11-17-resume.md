# Resuming interrupted work — 2026-11-17

Protocol inspired by the Handoff Debt paper, **not** its benchmark: 4 small Python tasks (`eval/resume`) in which a previous session left unfinished work and one fact in `.relai/notes.md` that a plain 'finish the job' gets wrong. Hidden tests grade the result. Conditions: `repo` (the agent is told to continue; the notes are in the repo, it may read them) and `relai` (same, plus the output of `relai handoff` in the prompt). Claude Haiku and Sonnet, Claude Code headless, 3 runs per cell. Fixtures written by the author of Relai.

Per task (passed/3, repo vs relai):

| task | haiku repo | haiku relai | sonnet repo | sonnet relai |
|---|---|---|---|---|
| rename | 1/3 | 3/3 | 3/3 | 3/3 |
| stale | 3/3 | 3/3 | 3/3 | 3/3 |
| dirty | 2/3 | 3/3 | 0/3 | 3/3 |
| money | 3/3 | 3/3 | 3/3 | 3/3 |

Reading: the handoff put the decisive note in front of the agent. Where the agent read `.relai/notes.md` on its own (stale, money) both conditions passed; where it did not (dirty for Sonnet 0/3, rename for Haiku 1/3) it broke the decision. Not shown: that a good AGENTS.md pointing to the notes would not close the gap, and nothing on real projects. Fixtures are the author's, n=3.
